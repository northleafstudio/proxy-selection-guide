## 三つの別の質問

「プロキシ」という一語に、次の三つの質問がまとめて入っていることがあります。

1. **出口 IP はどの種類のネットワークから来るか。** 住宅、データセンター、ISP、モバイルが通常指すものです。
2. **同じ出口がどれだけ長く割り当てられるか。** 固定とローテーションの違いで、スティッキーセッションと呼ばれることもあります。
3. **クライアントはどの方法で接続するか。** HTTP です。HTTPS 向けの [HTTP CONNECT](https://proxyvendors.com/ja/glossary/http-connect) トンネル、または [SOCKS5](https://proxyvendors.com/ja/glossary/socks5) が含まれます。

固定 IP でも他の顧客と共有されることがあります。SOCKS5 のエンドポイントは接続方法であり、IP の種類ではありません。同じ住宅またはデータセンターの出口に、複数のプロトコルで到達できることが多く、HTTP または HTTPS しか扱わない製品もあります。

## ネットワークの種類

**住宅。** 出口は家庭向けブロードバンドなどのコンシューマネットワークに関連づけられます。接続先がホスティングのアドレス帯に敏感なときや、普通の家庭の回線に見える地域が必要なときの一般的な選択です。住宅トラフィックはギガバイト単位で課金されることが多いです。プールは共有され、スティッキーや専用のオプションを買わない限り入れ替わります。このラベルは事業者または第三者データベースによる分類であり、IP 自体が持つ項目ではありません。

**データセンター。** 出口はホスティングまたはクラウドのネットワークから出ます。トラフィック単位や IP 単位の価格が低く、大量のリクエストでスループットが高いことがあります。多くのサイトはデータセンターのアドレス帯をより厳しく扱います。大きなプランを買う前に、その種類の出口で対象が有効な内容を返すか確認してください。

**ISP。静的住宅として売られることがあります。** アドレスは通常、家庭向けのインターネット接続事業者に登録され、プロキシのホスト自体はデータセンターにあることが多いです。ISP はその登録を指し、それだけでは出口が固定されるという意味ではありません。販売側はこのラベルを長めの割り当てと組にして売ることが多く、ログイン、IP 許可リスト、固定した地域に向きます。IP が専用か共有か、切断や更新のときに何が起きるか、本人確認があるかを確認してください。

**モバイル。** 出口は移動体通信事業者のネットワーク、多くは 4G または 5G から出ます。モバイル広告、事業者別のページ、携帯回線で内容が変わる地域向けコンテンツに使われます。課金はギガバイト、日、ポートのいずれかになることがあります。事業者と国の在庫、ローテーションの規則、利用上限を確認してください。モバイルの在庫は住宅プールより薄いことが多いです。

これらのラベルは品質の点数ではありません。対象がリクエストを受け入れるかは、出口、リクエストの出し方、対象自身の方針によります。

## 割り当て：固定、ローテーション、スティッキー

ローテーションは、通常、リクエストごと、または短い間隔で新しい出口を選ぶことを指します。スティッキーまたは固定は、通常、セッション中または契約期間中に同じ出口を保つことを指します。事業者によって言葉の使い方は揃っておらず、公式ページが二つのセッション時間を示すこともあります。同じ IP が必要な作業では、保持時間、それが切れる条件、代替 IP が保証されるかを正確に確認してください。

## ASN は四つ目の種類ではない

[ASN](https://proxyvendors.com/ja/glossary/asn) は、アドレスブロックを広告している経路事業者を示します。特定の通信事業者のネットワークが必要なとき、国を指定するより細かく選べます。国ではなく、その IP が住宅かデータセンターかも示しません。ASN を一つ指定するとプールは小さくなり、使える出口がなければリクエストは失敗することがあります。

## 種類を選んだら出口を確認する

プランページが説明しているのは、買うつもりの製品です。[IP チェック](https://proxyvendors.com/ja/ip-check) は、実際に受け取った公開 IP、組織、ASN を示し、必要なら DNS と WebRTC も調べられます。結果が購入した製品と合わないときは、量を増やす前に止めて解消してください。

具体的なプランを比べるときは、[購入前チェックリスト](./buying-checklist.md)を使ってください。
