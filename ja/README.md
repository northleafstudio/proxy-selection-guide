## このリポジトリの目的

ProxyVendors ですでに説明している区別を短く書き直しています。ネットワークの種類は接続プロトコルではなく、ASN は国でも IP の種類でもありません。トラフィックを買う前に確認すべき点もあります。単独で読めるようにまとめ、本サイトの詳しいページへリンクしています。

## ProxyVendors の関連ページ

ここより詳しい公開ページです。

- [ASN と ASN ターゲティング](https://proxyvendors.com/ja/glossary/asn) — ASN が示すのは経路を広告する事業者であり、国や IP の種類ではありません。
- [HTTP CONNECT トンネル](https://proxyvendors.com/ja/glossary/http-connect) — HTTP プロキシが HTTPS サイトへ届く仕組みと、407 が認証を求めている、または受け取った認証を受け入れなかったことを意味する理由。
- [SOCKS5 プロキシプロトコル](https://proxyvendors.com/ja/glossary/socks5) — バイト列を中継する接続方法であり、出口 IP の分類ではありません。
- [出口 IP の確認](https://proxyvendors.com/ja/ip-check) — 実際に割り当てられた公開 IP、組織、ASN を調べ、必要なら DNS と WebRTC も確認します。

## 読み方

製品名の意味がはっきりしないときは、先に[プロキシの種類](guides/proxy-types.md)を読み、その後で[購入前チェックリスト](guides/buying-checklist.md)を、事業者の現行の料金ページ、規約、小さな実作業の試用に当ててください。接続したあとは、プランの説明だけを信じず、IP 確認ページで出口を確かめてください。

このノートに誤りがある場合は、このスナップショットより、更新されている ProxyVendors の用語集と事業者のページを優先してください。
