## Do czego służy to repozytorium

Notatki powtarzają rozróżnienia już opisane w ProxyVendors: typ sieci nie jest protokołem połączenia, ASN nie jest krajem ani typem IP, a przed zakupem ruchu warto wykonać kilka sprawdzeń. To krótka adaptacja tego tła, napisana tak, by dało się ją czytać osobno, z odnośnikami do dłuższych stron witryny głównej.

## Dalsza lektura w ProxyVendors

Te publiczne strony wchodzą w większy szczegół niż notatki tutaj:

- [ASN i wybór według ASN](https://proxyvendors.com/pl/glossary/asn) — ASN nazywa operatora routingu, a nie kraj ani typ IP.
- [Tunel HTTP CONNECT](https://proxyvendors.com/pl/glossary/http-connect) — jak proxy HTTP dociera do witryny HTTPS i dlaczego 407 oznacza, że proxy wymaga uwierzytelnienia albo nie przyjęło otrzymanego uwierzytelnienia.
- [Protokół proxy SOCKS5](https://proxyvendors.com/pl/glossary/socks5) — metoda połączenia przekazująca bajty; to nie jest klasa adresu IP wyjścia.
- [Sprawdzenie IP wyjścia](https://proxyvendors.com/pl/ip-check) — publiczny adres IP, organizacja i ASN, które rzeczywiście otrzymano, z opcjonalnymi sprawdzeniami DNS i WebRTC.

## Jak korzystać z notatek

Jeśli etykiety produktu są niejasne, najpierw przeczytaj [przewodnik po typach proxy](guides/proxy-types.md), a potem zastosuj [listę zakupową](guides/buying-checklist.md) do aktualnej strony cen, warunków i małej próby na prawdziwym zadaniu. Po połączeniu potwierdź wyjście na stronie sprawdzania IP, zamiast polegać wyłącznie na opisie planu.

Jeśli w tych notatkach jest błąd, ważniejsze są aktualny słownik ProxyVendors i strony dostawcy.
