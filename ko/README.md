이 노트는 같은 운영자의 보조 자료입니다. 그 사이트와 무관한 제삼자의 리뷰가 아니고, 특정 사업자를 독립적으로 보증하는 글도 아닙니다. 어떤 내용이 사업자 문서에서 온 것이면 그 사업자의 현재 페이지를 기준으로 삼으십시오. 요금제 페이지와 도움말 문서는 서로 다를 수 있고, 둘 다 바뀝니다.

## 이 저장소의 목적

ProxyVendors에서 이미 설명한 구분을 다시 적습니다. 네트워크 유형은 연결 프로토콜이 아니고, ASN은 국가도 IP 유형도 아닙니다. 트래픽을 사기 전에 확인할 항목도 있습니다. 따로 읽을 수 있게 짧게 옮겼고, 본 사이트의 더 긴 페이지로 연결합니다.

## ProxyVendors에서 더 읽기

이 공개 페이지는 여기 노트보다 더 자세히 설명합니다.

- [ASN과 ASN 지정](https://proxyvendors.com/ko/glossary/asn) — ASN은 경로를 광고하는 사업자를 가리키며, 국가나 IP 유형이 아닙니다.
- [HTTP CONNECT 터널](https://proxyvendors.com/ko/glossary/http-connect) — HTTP 프록시가 HTTPS 사이트에 도달하는 방식과, 407이 프록시의 인증 요구 또는 받은 인증의 거부를 뜻하는 이유.
- [SOCKS5 프록시 프로토콜](https://proxyvendors.com/ko/glossary/socks5) — 바이트를 중계하는 연결 방법이며, 출구 IP의 종류가 아닙니다.
- [출구 IP 확인](https://proxyvendors.com/ko/ip-check) — 실제로 받은 공인 IP, 기관, ASN을 보고, 필요하면 DNS와 WebRTC도 확인합니다.

## 노트 사용 방법

제품 이름이 분명하지 않으면 먼저 [프록시 유형 안내](guides/proxy-types.md)를 읽고, [구매 확인 목록](guides/buying-checklist.md)을 사업자의 현재 가격 페이지, 약관, 작은 실제 작업 시험에 적용하십시오. 연결한 뒤에는 요금제 설명만 믿지 말고 IP 확인 페이지에서 출구를 확인하십시오.

이 노트에 오류가 있으면 이 스냅샷보다 ProxyVendors의 현재 용어집과 사업자 페이지를 우선하십시오.
