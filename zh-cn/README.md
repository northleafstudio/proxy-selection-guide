## 这个仓库做什么

笔记复述 ProxyVendors 上已经说明的几个区别：网络类型不是连接协议，ASN 不是国家，也不是 IP 类型；购买流量之前，有几项情况值得核对。这里是那部分背景的简短改写，可以单独阅读，并链到主站上更完整的页面。

## ProxyVendors 上的延伸阅读

这些公开页面比这里的笔记更详细：

- [ASN 与 ASN 定向](https://proxyvendors.com/zh-cn/glossary/asn) — ASN 标识的是宣告地址的路由运营商，不是国家，也不是 IP 类型。
- [HTTP CONNECT 隧道](https://proxyvendors.com/zh-cn/glossary/http-connect) — HTTP 代理如何访问 HTTPS 网站，以及 407 为何表示代理要求身份验证，或没有接受收到的身份验证。
- [SOCKS5 代理协议](https://proxyvendors.com/zh-cn/glossary/socks5) — 一种按字节转发的连接方式，不是一类出口 IP。
- [出口 IP 检查](https://proxyvendors.com/zh-cn/ip-check) — 查看实际得到的公网 IP、机构和 ASN，并可按需检查 DNS 与 WebRTC。

## 如何使用这些笔记

如果产品名称不清楚，先读[代理类型指南](guides/proxy-types.md)，再用[购买核对清单](guides/buying-checklist.md)对照服务商当前的价格页、条款，并做一次小规模的真实任务试用。连上之后，到 IP 检查页确认出口，不要只相信套餐说明。

如果这些笔记有错误，请以 ProxyVendors 上仍在更新的术语表和服务商页面为准。
