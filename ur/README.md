# Northleaf Studio کے پراکسی نوٹس

یہ ذخیرہ پراکسی IP کی اقسام، کنکشن کے طریقوں اور خریداری سے پہلے ایک عملی فہرست جمع کرتا ہے۔ اسے **Northleaf Studio** شائع کرتا ہے، جو [ProxyVendors](https://proxyvendors.com/ur/) بھی چلاتا ہے، یعنی پراکسی فراہم کنندگان کا موازنہ کرنے والی ڈائریکٹری۔

یہ نوٹس اسی فریق کا ضمنی مواد ہیں۔ یہ اس سائٹ سے غیر متعلق تیسرے فریق کا جائزہ نہیں، اور کسی فراہم کنندہ کی آزادانہ توثیق نہیں۔ اگر کوئی بات فراہم کنندہ کی دستاویز سے آئی ہو تو اس کی موجودہ صفحہ حوالہ ہے۔ منصوبے کے صفحات اور مدد کے مضامین آپس میں مختلف ہو سکتے ہیں، اور دونوں بدل سکتے ہیں۔

## یہ ذخیرہ کس لیے ہے

نوٹس وہ امتیاز دہراتے ہیں جو ProxyVendors پہلے ہی بیان کرتا ہے: نیٹ ورک کی قسم کنکشن پروٹوکول نہیں، ASN ملک نہیں اور IP کی قسم نہیں، اور ٹریفک خریدنے سے پہلے چند جانچیں اہم ہیں۔ یہ اس پس منظر کی مختصر تطبیق ہے، الگ پڑھنے کے لیے لکھی گئی ہے، اور مرکزی سائٹ کے لمبے صفحات سے جڑتی ہے۔

## فائلیں

- [خریداری کی فہرست](guides/buying-checklist.md) — خریدنے سے پہلے لاگت، سیشن، پروٹوکول اور تصدیق کی جانچیں۔

## ProxyVendors پر مزید مطالعہ

یہ عوامی صفحات یہاں کے نوٹس سے زیادہ تفصیل میں جاتے ہیں:

- [ASN اور ASN ہدف](https://proxyvendors.com/ur/glossary/asn) — ASN روٹنگ چلانے والے کو نام دیتا ہے، ملک یا IP کی قسم کو نہیں۔
- [HTTP CONNECT سرنگ](https://proxyvendors.com/ur/glossary/http-connect) — HTTP پراکسی HTTPS سائٹ تک کیسے پہنچتا ہے، اور 407 کا مطلب یہ کیوں ہے کہ پراکسی تصدیق مانگ رہا ہے یا موصول تصدیق قبول نہیں کی۔
- [SOCKS5 پراکسی پروٹوکول](https://proxyvendors.com/ur/glossary/socks5) — کنکشن کا طریقہ جو بائٹس آگے بھیجتا ہے؛ یہ اخراج IP کی کوئی جماعت نہیں۔
- [اخراج IP کی جانچ](https://proxyvendors.com/ur/ip-check) — وہ عوامی IP، ادارہ اور ASN جو واقعی ملا، اختیاری DNS اور WebRTC جانچ کے ساتھ۔

## نوٹس کیسے استعمال کریں

اگر مصنوع کا نام واضح نہ ہو تو پہلے [پراکسی کی اقسام کی رہنما](guides/proxy-types.md) پڑھیں، پھر [خریداری کی فہرست](guides/buying-checklist.md) فراہم کنندہ کے موجودہ قیمتی صفحے، شرائط اور حقیقی کام کے چھوٹے تجربے پر لگائیں۔ جڑنے کے بعد اخراج IP جانچ کے صفحے پر دیکھیں، صرف منصوبے کی وضاحت پر بھروسا نہ کریں۔

اگر ان نوٹس میں غلطی ہو تو ProxyVendors کی تازہ لغت اور فراہم کنندہ کے صفحات کو ترجیح دیں۔
