## تین الگ سوال

لوگ اکثر تین سوالات ایک لفظ، «پراکسی»، میں سمیٹ دیتے ہیں:

1. **اخراج IP کس قسم کے نیٹ ورک سے آتا ہے؟** رہائشی، ڈیٹا سینٹر، ISP اور موبائل کا عام مطلب یہی ہے۔
2. **وہی اخراج کتنی دیر تک مختص رہتا ہے؟** یہ مستقل اور گھومتی تخصیص کا فرق ہے، جسے کبھی چپکتا سیشن بھی کہتے ہیں۔
3. **کلائنٹ کیسے جڑتا ہے؟** یہ HTTP ہے، جس میں HTTPS کے لیے [HTTP CONNECT](https://proxyvendors.com/ur/glossary/http-connect) سرنگ یا [SOCKS5](https://proxyvendors.com/ur/glossary/socks5) شامل ہے۔

مستقل IP پھر بھی دوسرے گاہکوں کے ساتھ مشترک ہو سکتا ہے۔ SOCKS5 سرا کنکشن کا طریقہ ہے، IP کی قسم نہیں۔ ایک ہی رہائشی یا ڈیٹا سینٹر اخراج اکثر ایک سے زیادہ پروٹوکول سے پہنچا جا سکتا ہے، اور کچھ مصنوعات صرف HTTP یا HTTPS سنبھالتی ہیں۔

## نیٹ ورک کی اقسام

**رہائشی۔** اخراج صارف یا براڈبینڈ نیٹ ورک سے جڑا ہوتا ہے۔ یہ عام انتخاب ہے جب ہدف ہوسٹنگ کی حدود کے بارے میں حساس ہو، یا ایسی جگہ چاہیے ہو جو عام گھریلو کنکشن جیسی لگے۔ رہائشی ٹریفک اکثر فی گیگابائٹ بل ہوتا ہے۔ پول مشترک ہوتے ہیں اور گھومتے ہیں، جب تک چپکتا یا مختص اختیار نہ خریدا جائے۔ یہ لیبل فراہم کنندہ یا تیسرے فریق کے ڈیٹا بیس کی درجہ بندی ہے؛ یہ خود IP کا کوئی خانہ نہیں۔

**ڈیٹا سینٹر۔** اخراج ہوسٹنگ یا کلاؤڈ نیٹ ورک سے آتا ہے۔ یہ مصنوعات اکثر ٹریفک کی اکائی یا IP کے لحاظ سے سستی ہوتی ہیں، اور بڑی درخواستوں پر زیادہ گنجائش دے سکتی ہیں۔ بہت سی سائٹیں ڈیٹا سینٹر کی حدود کے ساتھ سخت ہوتی ہیں۔ بڑا منصوبہ خریدنے سے پہلے دیکھیں کہ ہدف اس قسم کے اخراج سے درست مواد لوٹاتا ہے یا نہیں۔

**ISP، کبھی مستقل رہائشی کے نام سے بکتا ہے۔** پتہ عام طور پر گھریلو انٹرنیٹ فراہم کنندہ کے نام رجسٹر ہوتا ہے، جبکہ خود پراکسی میزبان اکثر ڈیٹا سینٹر میں ہوتا ہے۔ ISP اس رجسٹریشن کا نام ہے؛ یہ خود یہ معنی نہیں رکھتا کہ اخراج قائم رہے۔ فروخت کنندہ اکثر اس لیبل کو لمبی تخصیص کے ساتھ جوڑتے ہیں، جو لاگ ان، اجازت یافتہ IP فہرستوں اور مقررہ جگہ کے لیے موزوں ہے۔ تصدیق کریں کہ IP آپ کے لیے مختص ہے یا مشترک، منقطع ہونے یا تجدید پر کیا ہوتا ہے، اور شناخت کی جانچ لگتی ہے یا نہیں۔

**موبائل۔** اخراج موبائل آپریٹر کے نیٹ ورک سے آتا ہے، عام طور پر 4G یا 5G۔ یہ موبائل اشتہاروں، آپریٹر کے مخصوص صفحات اور ایسے علاقائی مواد کے لیے استعمال ہوتا ہے جو سیلولر نیٹ ورک پر مختلف ہو۔ بلنگ فی گیگابائٹ، فی دن یا فی پورٹ ہو سکتی ہے۔ آپریٹر اور ملک کا ذخیرہ، گردش کے قواعد اور استعمال کی حدیں دیکھیں، کیونکہ موبائل ذخیرہ رہائشی پولوں سے اکثر پتلا ہوتا ہے۔

ان میں سے کوئی لیبل معیار کا نمبر نہیں۔ ہدف درخواست قبول کرے یا نہ کرے، یہ اخراج، درخواست کے انداز اور ہدف کی اپنی پالیسی پر منحصر ہے۔

## تخصیص: مستقل، گھومتی اور چپکتی

گھومتی کا عام مطلب یہ ہے کہ ہر درخواست پر، یا مختصر وقفے پر، نیا اخراج چنا جاتا ہے۔ چپکتی یا مستقل کا عام مطلب یہ ہے کہ وہی اخراج سیشن یا کرایے کی مدت تک رہتا ہے۔ فراہم کنندہ یہ الفاظ ایک جیسے نہیں استعمال کرتے، اور سرکاری صفحات کبھی دو مختلف سیشن مدات دیتے ہیں۔ اگر کام کو وہی IP چاہیے تو ٹھیک ٹھیک برقرار رہنے کا وقت، اسے توڑنے والی شرطیں، اور متبادل IP کی ضمانت حاصل کریں۔

## ASN چوتھی قسم نہیں

[ASN](https://proxyvendors.com/ur/glossary/asn) اس روٹنگ چلانے والے کی شناخت کرتا ہے جو پتوں کا بلاک اعلان کرتا ہے۔ جب ایک آپریٹر کا نیٹ ورک چاہیے ہو تو یہ ملک سے زیادہ دقیق ہو سکتا ہے۔ یہ ملک نہیں، اور یہ نہیں بتاتا کہ IP رہائشی ہے یا ڈیٹا سینٹر کا۔ ایک ASN مانگنے سے پول بھی سکڑتا ہے؛ اگر اخراج دستیاب نہ ہو تو درخواست ناکام ہو سکتی ہے۔
