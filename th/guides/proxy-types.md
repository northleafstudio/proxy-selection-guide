# ชนิดของพร็อกซี: เครือข่าย การกำหนด และโพรโทคอล

คู่มือนี้จัดพิมพ์โดย Northleaf Studio ซึ่งเป็นผู้ดำเนินงาน [ProxyVendors](https://proxyvendors.com/th/) ด้วย เว็บนี้เป็นสารบบสำหรับเปรียบเทียบผู้ให้บริการตามงาน เซสชัน สถานที่ และค่าใช้จ่าย นี่เป็นเอกสารพื้นหลังจากฝ่ายเดียวกัน ไม่ใช่บทวิจารณ์อิสระของเว็บนั้นหรือของผู้ให้บริการโดยบุคคลที่สามซึ่งไม่เกี่ยวข้อง ป้ายชื่อผลิตภัณฑ์เปลี่ยนได้ และหน้าทางการสองหน้าของผู้ให้บริการรายเดียวกันอาจไม่ตรงกัน ให้ใช้บทนี้เป็นแผนที่ของคำ แล้วตรวจรายละเอียดในเอกสารปัจจุบันของผู้ให้บริการ

## สามคำถามที่ต่างกัน

คนมักยัดสามคำถามไว้ในคำเดียวว่า “พร็อกซี”

1. **IP ทางออกมาจากเครือข่ายชนิดใด** นี่คือความหมายปกติของที่อยู่อาศัย ศูนย์ข้อมูล ISP และมือถือ
2. **ทางออกเดิมถูกกำหนดไว้นานแค่ไหน** นี่คือความต่างระหว่างคงที่กับการหมุน บางครั้งเรียกเซสชันแบบเหนียว
3. **ไคลเอนต์เชื่อมต่ออย่างไร** นี่คือ HTTP ซึ่งรวมอุโมงค์ [HTTP CONNECT](https://proxyvendors.com/th/glossary/http-connect) ที่ใช้กับ HTTPS หรือ [SOCKS5](https://proxyvendors.com/th/glossary/socks5)

IP แบบคงที่ยังอาจใช้ร่วมกับลูกค้ารายอื่นได้ จุดเชื่อม SOCKS5 เป็นวิธีเชื่อมต่อ ไม่ใช่ชนิดของ IP ทางออกที่อยู่อาศัยหรือศูนย์ข้อมูลเดียวกันมักเข้าถึงได้มากกว่าหนึ่งโพรโทคอล และผลิตภัณฑ์บางอย่างรองรับเพียง HTTP หรือ HTTPS

## ชนิดของเครือข่าย

**ที่อยู่อาศัย** ทางออกผูกกับเครือข่ายผู้บริโภคหรือบรอดแบนด์ เป็นทางเลือกปกติเมื่อปลายทางไวต่อช่วงที่อยู่ของโฮสติ้ง หรือเมื่อต้องการตำแหน่งที่ดูเหมือนการเชื่อมต่อบ้านธรรมดา ทราฟฟิกที่อยู่อาศัยมักคิดตามกิกะไบต์ พูลใช้ร่วมกันและหมุน เว้นแต่จะซื้อตัวเลือกแบบเหนียวหรือแบบเฉพาะ ป้ายนี้เป็นการจัดประเภทของผู้ให้บริการหรือของฐานข้อมูลบุคคลที่สาม ไม่ใช่ฟิลด์ที่ IP พกติดมาเอง

**ศูนย์ข้อมูล** ทางออกมาจากเครือข่ายโฮสติ้งหรือคลาวด์ ผลิตภัณฑ์เหล่านี้มักถูกกว่าต่อหน่วยทราฟฟิกหรือต่อ IP และอาจให้ปริมาณงานสูงกว่าเมื่อมีคำขอจำนวนมาก เว็บจำนวนมากปฏิบัติต่อช่วงที่อยู่ศูนย์ข้อมูลเข้มงวดกว่า ก่อนซื้อแพ็กเกจใหญ่ ให้ตรวจว่าปลายทางส่งเนื้อหาที่ใช้ได้ผ่านทางออกชนิดนี้หรือไม่

**ISP บางครั้งขายในชื่อที่อยู่อาศัยแบบคงที่** ที่อยู่มักจดทะเบียนในชื่อผู้ให้บริการอินเทอร์เน็ตสำหรับบ้าน ขณะที่โฮสต์ของพร็อกซีเองมักอยู่ในศูนย์ข้อมูล ISP บอกถึงการจดทะเบียนนั้น แต่โดยตัวมันเองไม่ได้หมายความว่าทางออกจะคงที่ ผู้ขายมักจับคู่ป้ายนี้กับการกำหนดที่นานขึ้น ซึ่งเข้ากับการเข้าสู่ระบบ รายการ IP ที่อนุญาต และตำแหน่งคงที่ ให้ยืนยันว่า IP เป็นแบบเฉพาะหรือใช้ร่วมกัน จะเกิดอะไรขึ้นเมื่อหลุดหรือต่ออายุ และมีการตรวจตัวตนหรือไม่

**มือถือ** ทางออกมาจากเครือข่ายผู้ให้บริการมือถือ โดยปกติคือ 4G หรือ 5G ใช้กับโฆษณาบนมือถือ หน้าที่เฉพาะของผู้ให้บริการ และเนื้อหาตามภูมิภาคที่ต่างกันบนเครือข่ายเซลลูลาร์ การคิดเงินอาจเป็นต่อกิกะไบต์ ต่อวัน หรือต่อพอร์ต ให้ตรวจสต็อกตามผู้ให้บริการและประเทศ กฎการหมุน และขีดจำกัดการใช้ เพราะสินค้าคงคลังมือถือมักบางกว่าพูลที่อยู่อาศัย

ป้ายเหล่านี้ไม่ใช่คะแนนคุณภาพ ปลายทางจะรับคำขอหรือไม่ขึ้นกับทางออก รูปแบบคำขอ และนโยบายของปลายทางเอง

## การกำหนด: คงที่ หมุน และเหนียว

การหมุนมักหมายถึงการเลือกทางออกใหม่ต่อคำขอ หรือในช่วงเวลาสั้น การเหนียวหรือคงที่มักหมายถึงการถือทางออกเดิมไว้ตลอดเซสชันหรือระยะเช่า ผู้ให้บริการไม่ได้ใช้คำเหล่านี้เหมือนกัน และหน้าทางการบางครั้งให้ระยะเซสชันสองค่า ถ้างานต้องใช้ IP เดิม ให้ขอเวลายึดที่แน่นอน เงื่อนไขที่ทำให้มันขาด และมีการรับประกัน IP ทดแทนหรือไม่

## ASN ไม่ใช่ชนิดที่สี่

[ASN](https://proxyvendors.com/th/glossary/asn) ระบุผู้ให้บริการเส้นทางที่ประกาศช่วงที่อยู่ มันละเอียดกว่าประเทศเมื่อต้องการเครือข่ายของผู้ให้บริการรายหนึ่ง มันไม่ใช่ประเทศ และไม่ได้บอกว่า IP เป็นที่อยู่อาศัยหรือศูนย์ข้อมูล การขอ ASN เดียวทำให้พูลเล็กลง ถ้าไม่มีทางออกที่ใช้ได้ คำขออาจล้มเหลว

## หลังจากเลือกชนิดแล้ว ให้ตรวจทางออก

หน้าแพ็กเกจอธิบายผลิตภัณฑ์ที่ตั้งใจจะซื้อ [การตรวจ IP](https://proxyvendors.com/th/ip-check) แสดง IP สาธารณะ องค์กร และ ASN ที่ได้รับจริง พร้อมการตรวจ DNS และ WebRTC ที่เลือกได้ ถ้าผลไม่ตรงกับผลิตภัณฑ์ที่ซื้อ ให้หยุดและแก้ก่อนขยายปริมาณ
