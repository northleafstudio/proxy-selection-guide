# รายการสั้นก่อนซื้อแพ็กเกจพร็อกซี

รายการนี้จัดพิมพ์โดย Northleaf Studio ซึ่งเป็นผู้ดำเนินงาน [ProxyVendors](https://proxyvendors.com/th/) ด้วย เป็นเอกสารประกอบจากฝ่ายเดียวกัน ไม่ใช่คำแนะนำของบุคคลที่สามซึ่งไม่เกี่ยวข้อง ให้นำไปเทียบกับหน้าราคาปัจจุบัน ข้อกำหนด และการทดลองเล็ก ๆ รายการนี้ไม่รับประกันว่าแพ็กเกจจะใช้ได้กับปลายทางของคุณ

## 1. เขียนงานให้ชัด แล้วเลือกเครือข่าย

จดว่าทางออกต้องทำอะไร การเข้าสู่ระบบที่คงอยู่นาน ข้อมูลสาธารณะตามพื้นที่ คำขอปริมาณมาก หรือการทดสอบผู้ให้บริการมือถือ จับคู่งานนั้นกับชนิดเครือข่ายตาม[คู่มือชนิดของพร็อกซี](./proxy-types.md) คือที่อยู่อาศัย ศูนย์ข้อมูล ISP หรือมือถือ ถ้าหน้าแรกกับหน้าราคาโฆษณาราคาเริ่มต้นหรือจำนวนประเทศไม่ตรงกัน ให้จดทั้งสองค่า แล้วถามว่าตัวเลขใดใช้กับระดับที่คุณจะซื้อจริง

## 2. ตรวจพฤติกรรมของเซสชัน

ตัดสินว่าต้องการทางออกเดิมเป็นนาที เป็นชั่วโมง หรือตลอดระยะเช่า หรือต้องการทางออกใหม่ทุกคำขอ ยืนยันระยะแบบเหนียวหรือคงที่ สิ่งที่ทำให้มันขาด และ IP ที่หลุดจะถูกแทนหรือไม่ เอกสารทางการบางครั้งให้เวลายึดสองค่า ให้ถือว่ายังไม่ยุติจนกว่าผู้ให้บริการจะยืนยัน

## 3. ยืนยันโพรโทคอลและการยืนยันตัวตน

HTTP ซึ่งรวม [HTTP CONNECT](https://proxyvendors.com/th/glossary/http-connect) สำหรับเว็บ HTTPS ไม่ใช่สิ่งเดียวกับ [SOCKS5](https://proxyvendors.com/th/glossary/socks5) ผลิตภัณฑ์ที่อยู่อาศัยบางอย่างรองรับเพียง HTTP และ HTTPS ถ้าต้องการ SOCKS5 หรือ UDP ผ่าน SOCKS5 ให้ตรวจว่าทั้งผลิตภัณฑ์และไคลเอนต์รองรับ ยืนยันโฮสต์ทางเข้า พอร์ต และวิธียืนยันตัวตน คือชื่อผู้ใช้กับรหัสผ่าน รายการ IP ที่อนุญาต หรือทั้งสองอย่าง การตอบ 407 ระหว่าง CONNECT มาจากพร็อกซี สถานะนี้หมายถึง Proxy Authentication Required คือพร็อกซีต้องการการยืนยันตัวตน หรือไม่ยอมรับการยืนยันตัวตนที่ได้รับ อุโมงค์ไม่ได้ถูกสร้าง และเว็บปลายทางไม่เห็นคำขอนั้น

## 4. รวมค่าใช้จ่ายจริง

มองให้พ้นราคาต่อหน่วยบนหัวข้อ จดปริมาณซื้อขั้นต่ำ อายุหรือวันหมดของแพ็ก ค่าส่วนเกิน ความสูญเสียจากการลองใหม่ ค่าเพิ่มเมื่อเจาะจงละเอียด ภาษีมูลค่าเพิ่ม และการเติมหรือต่ออายุอัตโนมัติ ราคาที่เน้นอาจเป็นของระดับปริมาณมาก ไม่ใช่แพ็กที่คุณจะเริ่มใช้ ถ้าการทดลองต้องใช้บัตรและเปิดการเติมอัตโนมัติ ให้ตัดสินใจว่าจะปิดก่อนเริ่มหรือไม่

## 5. อ่านกฎการทดลอง การคืนเงิน และการเข้าใช้

ตรวจขนาดและระยะเวลาทดลอง ช่วงคืนเงิน เพดานการใช้ และเงื่อนไขว่าการคืนเงินต้องมีหลักฐานความขัดข้องของเครือข่ายหรือไม่ สังเกตการตรวจตัวตนหรือ KYC หมวดที่ถูกบล็อก เช่น เว็บธนาคารหรือหน่วยงานรัฐ และขีดการใช้ที่เป็นธรรมของผลิตภัณฑ์แบบคงที่หรือแบบเฉพาะ ถ้าแหล่งที่มาหรือการปฏิบัติตามกฎสำคัญ ให้ขอเอกสารจากผู้ให้บริการ อย่าอาศัยเพียงข้อความโฆษณา

## 6. ค้นเครือข่าย แล้วทดลอง

ถ้าต้องการผู้ให้บริการรายหนึ่ง ให้ยืนยันว่ามีการรองรับ[การเลือกตาม ASN](https://proxyvendors.com/th/glossary/asn) และจะเกิดอะไรขึ้นเมื่อไม่มีทางออก จากนั้นทำงานจริงขนาดเล็ก ดูว่าปลายทางตอบกลับใช้ได้หรือไม่ เซสชันหลุดหรือไม่ ตำแหน่งแม่นหรือไม่ และใช้ทราฟฟิกไปเท่าใดจริง หลังเชื่อมต่อแล้ว ใช้[การตรวจ IP](https://proxyvendors.com/th/ip-check) เทียบ IP สาธารณะ องค์กร และ ASN กับผลิตภัณฑ์ที่ซื้อ และรันการตรวจ DNS กับ WebRTC ถ้าเส้นทางเหล่านั้นสำคัญ
