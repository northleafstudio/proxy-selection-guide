# บันทึกเรื่องพร็อกซีจาก Northleaf Studio

ที่เก็บนี้รวบรวมบันทึกที่ใช้ได้นาน เกี่ยวกับชนิดของ IP พร็อกซี วิธีเชื่อมต่อ และรายการตรวจสอบก่อนซื้อ ผู้จัดพิมพ์คือ **Northleaf Studio** ซึ่งเป็นผู้ดำเนินงาน [ProxyVendors](https://proxyvendors.com/th/) ด้วย เว็บนี้เป็นสารบบสำหรับเปรียบเทียบผู้ให้บริการพร็อกซี

บันทึกเหล่านี้เป็นเอกสารประกอบจากฝ่ายเดียวกัน ไม่ใช่บทวิจารณ์ของบุคคลที่สามซึ่งไม่เกี่ยวข้องกับเว็บ และไม่ใช่การรับรองผู้ให้บริการรายใดอย่างอิสระ หากข้อความหนึ่งมาจากเอกสารของผู้ให้บริการ ให้ยึดหน้าปัจจุบันของผู้ให้บริการนั้นเป็นหลัก หน้าแพ็กเกจกับบทความช่วยเหลืออาจไม่ตรงกัน และทั้งสองอย่างเปลี่ยนแปลงได้

## ที่เก็บนี้มีไว้ทำอะไร

บันทึกย้ำความแตกต่างที่ ProxyVendors อธิบายไว้แล้ว ชนิดของเครือข่ายไม่ใช่โพรโทคอลการเชื่อมต่อ ASN ไม่ใช่ประเทศและไม่ใช่ชนิดของ IP และมีการตรวจสอบหลายอย่างที่สำคัญก่อนซื้อทราฟฟิก นี่เป็นบทปรับให้สั้นของพื้นความรู้นั้น เขียนให้อ่านได้โดยลำพัง พร้อมลิงก์ไปยังหน้าที่ยาวกว่าบนเว็บหลัก

## อ่านเพิ่มบน ProxyVendors

หน้าสาธารณะเหล่านี้ลงรายละเอียดมากกว่าบันทึกที่นี่

- [ASN และการเลือกตาม ASN](https://proxyvendors.com/th/glossary/asn) — ASN ระบุผู้ให้บริการที่ประกาศเส้นทาง ไม่ใช่ประเทศและไม่ใช่ชนิดของ IP
- [อุโมงค์ HTTP CONNECT](https://proxyvendors.com/th/glossary/http-connect) — พร็อกซี HTTP ไปถึงเว็บ HTTPS อย่างไร และเหตุใด 407 จึงหมายความว่าพร็อกซีต้องการการยืนยันตัวตน หรือไม่ยอมรับการยืนยันตัวตนที่ได้รับ
- [โพรโทคอลพร็อกซี SOCKS5](https://proxyvendors.com/th/glossary/socks5) — วิธีเชื่อมต่อที่ส่งต่อไบต์ ไม่ใช่ประเภทของ IP ทางออก
- [ตรวจ IP ทางออก](https://proxyvendors.com/th/ip-check) — IP สาธารณะ องค์กร และ ASN ที่ได้รับจริง พร้อมการตรวจ DNS และ WebRTC เมื่อต้องการ

## วิธีใช้บันทึก

ถ้าป้ายชื่อผลิตภัณฑ์ไม่ชัด ให้อ่าน[คู่มือชนิดของพร็อกซี](guides/proxy-types.md)ก่อน แล้วใช้[รายการก่อนซื้อ](guides/buying-checklist.md)เทียบกับหน้าราคาปัจจุบัน ข้อกำหนด และการทดลองเล็ก ๆ กับงานจริง หลังเชื่อมต่อแล้ว ให้ยืนยันทางออกที่หน้าตรวจ IP อย่าเชื่อเพียงคำอธิบายแพ็กเกจ
